2. ATTRIBUTION AND CREDITS
---------------------------

  The Mod builds upon and draws inspiration from the following projects.
  The Author respectfully acknowledges and credits these works:

  a. Base Mod:
     - Tensura: Reincarnated
       by ManasMods (ManasCore Team)
       https://www.curseforge.com/minecraft/mc-mods/tensura-reincarnated
       The foundational Tensura mod for Minecraft. All race, skill,
       EP, magicule, and awakening systems in the Mod are built on
       Tensura: Reincarnated's architecture. The Mod's race and skill
       registries extend Tensura's framework, and its commands and
       configuration integrate with Tensura's systems.

  b. Core Libraries:
     - ManasCore
       by ManasMods
       https://www.curseforge.com/minecraft/mc-mods/manascore
       The shared API providing race registry, skill registry, player
       capabilities, config injection, and event infrastructure used
       by the Mod. ManasCore is the backbone of the Mod's integration
       with Tensura: Reincarnated.

     - GeckoLib
       by GeckoStudio
       https://www.curseforge.com/minecraft/mc-mods/geckolib
       The model and animation library used for custom entity and
       player model rendering.

     - Architectury
       by Architectury Team
       https://www.curseforge.com/minecraft/mc-mods/architectury-api
       The cross-platform registry API used for DeferredRegister
       and mod event bus integration.

  c. Addon Inspiration:
     The following Tensura addons served as reference implementations
     for the Mod's addon architecture, config injection patterns, and
     race/skill registration approaches:

     - TR Addon
       by blocker315
       https://www.modrinth.com/mod/tr-addon
       Demonstrated the pattern for injecting custom races into
       Tensura's config system, using custom skill namespaces, and
       integrating with ManasCore's race and skill APIs.

     - Ragnarok Races
       by dominickwd04
       https://www.curseforge.com/minecraft/mc-mods/ragnarok-races
       Provided reference for config-driven race definitions,
       intrinsic skill assignments per race stage, and evolution
       requirement implementations.

     - Mysticism
       by Memoires
       Referenced for awakening path integration patterns and
       skill progression design within the Tensura framework.

  d. Modding Framework:
     - NeoForge
       by NeoForged
       https://neoforged.net/
       The mod loader and API powering the Mod's runtime, event
       system, registry management, and network packet handling.

     - NeoForge MDK (Mod Development Kit)
       by NeoForged
       https://github.com/NeoForged/MDK
       The project template used as the base for the Mod's Gradle
       build configuration. The MDK template files are licensed
       under the MIT License (see TEMPLATE_LICENSE.txt if present).

  e. Community Resources:
     - Tensura Wiki (tensura.wiki.gg)
       Referenced for race evolution data, EP thresholds, magicule
       values, skill descriptions, and awakening mechanics from the
       Tensura: Reincarnated mod.

     - Forge/NeoForge Documentation
       https://docs.neoforged.net/
       Official modding documentation used throughout development.

     - Jabelar's Modding Tutorials
       Referenced for Java modding patterns and best practices.

  f. The Author acknowledges that all original Tensura content
     (races, skills, characters, entities, and mechanics) are the
     intellectual property of Fuse (the original light novel author)
     and the respective mod developers. The Mod does not claim
     ownership of any Tensura: Reincarnated content, ManasCore APIs,

  g. Any trademarks, service marks, or trade names of Tensura,
